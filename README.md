# NarrowScape

Project website prepared for https://narrowscape.github.io/.

This repository contains the presentation website only. Scenario-generation code is coming soon. Only animated image previews and summary results are distributed; original videos, simulation traces, recorded replay trajectories, credentials and local run logs are excluded. Public previews can still be saved by a browser.
